# HomeVault Product Roadmap

## Phase 1 — V1 MVP

Goal: validate demand.

Core records:
- Home
- Boiler
- Vehicle
- Appliances
- Documents
- Reminders

## Phase 2 — Real accounts

Goal: turn the prototype into a genuine multi-user application.

- Registration
- Login
- Password reset
- Email verification
- Cloud database
- Secure file storage
- User-specific data
- Household sharing

## Phase 3 — Retention

Goal: give users a reason to return.

- Automated reminders
- Email notifications
- Push notifications
- Better document organisation
- Expiry notifications
- Activity timeline
- Dashboard improvements

## Phase 4 — Monetisation

Goal: establish a sustainable SaaS business.

Potential model:

Free:
- One home
- Limited records
- Limited documents
- Basic reminders

Premium:
- Unlimited records
- Unlimited documents
- Household sharing
- Advanced reminders
- Document storage
- Priority features

## Phase 5 — Expansion

Potential future records:
- Garden equipment
- Smart home devices
- Solar panels
- Heat pumps
- Electrical systems
- Plumbing
- Furniture
- Home improvements
- Renovations
- Contents inventory
- Pets
- Important household contacts
